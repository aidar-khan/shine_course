# Shine Book

Текстовая рабочая область проекта Shine для GitHub и облачного Codex.

## Что здесь хранится

- оглавление пяти частей и текущих глав;
- источники внутри каждой главы, к которой они сейчас относятся;
- копии распознаваний, коротких аннотаций и подробных смысловых пересказов;
- основные смыслы, будущие черновики и итоговые главы книги.

Видео и аудио сюда не копируются и не загружаются в GitHub. Они остаются в локальном видеокурсе. Каждая карточка источника содержит названия соответствующих локальных медиафайлов.

В каждой главе есть собственная папка `Источники`. В ней лежат распознавание, аннотация, подробный пересказ и карточка каждого рассказа, относящегося к этой главе. Одна глава может собираться из нескольких видеорассказов, голосовых рассказов и текстовых материалов.

Если один источник позднее понадобится нескольким главам, основной экземпляр можно оставить в наиболее подходящей главе, а в остальных главах указать на него ссылку. Связи перечисляются в `source.yml`, поэтому порядок книги можно менять без переименования исходных медиафайлов.
