# Модель учебного блока

Блок — минимальная единица знания или навыка, освоение которой можно проверить. Блок может содержать дочерние блоки произвольной глубины.

| Поле | Смысл |
|---|---|
| ID | Постоянный уникальный номер, не зависит от части и позиции |
| Название и синонимы | Употребляемые автором названия |
| Тип | Внешняя практика / внутренняя практика / теория / принцип / правило / предупреждение / вариант / другое |
| Путь | Часть → направление → тема → подблок (уровней сколько требуется) |
| Цель | Для чего ученик изучает это |
| Содержание | Что именно следует знать или делать; только подтверждённое |
| Критерий освоения | Проверяемое «ученик может объяснить / различить / выполнить» |
| Зависимости | Что знать или уметь до этого |
| Варианты и связи | Вложенные приёмы, альтернативы, повторения в других частях |
| Источники | Файлы, видеоидентификаторы или ссылки в основном репозитории |
| Уверенность | Черновик / уточняется / подтверждено автором |
| Вопросы | Чего пока не хватает для полноценной учебной единицы |

Прогресс ученика хранить отдельно от полноты описания: не начато / изучено / проверено на практике. Теоретический блок не требует «выполнено на практике», если у него нет практической составляющей.

Не использовать номер части как неизменяемый ID: размещение может измениться. Пример идентификатора: `BLK-001`; иерархия записывается отдельно. Реконструкция по устным рассказам может быть неполной: при отсутствии фактов ставить «не уточнено», а не выдумывать.
